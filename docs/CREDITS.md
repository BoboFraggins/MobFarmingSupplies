# Credits

The mod is built with [Architectury](https://docs.architectury.dev/), which lets one codebase run
on both NeoForge and Fabric.

Mob Farming Supplies began as an homage to
[Mob Grinding Utils](https://github.com/vadis365/Mob-Grinding-Utils) by vadis365, and several of
its farming blocks follow that mod's design.
